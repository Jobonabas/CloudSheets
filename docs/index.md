# CloudSheets

Welcome to the official wiki of the **CloudSheets** project.

---

## Project Goal

**cloud based web application for real time collaboration working on simple sheets** .

Users can:
- create an account
- Create and manage their own sheets  
- edit their sheets
- Give access to other users their sheet for collaborative working  
- add Multi-Factor-Authentification to their account
