# CloudForms
geile cloudforms

## Backend (Node.js + Fastify)

### Build & Start

1. Install dependencies:
	```bash
	cd backend
	npm install
	```
2. Build backend (TypeScript → JavaScript):
	```bash
	npm run build
	```
3. Start backend:
	```bash
	npm start
	```

### API Endpoints

#### Health Check
**GET** `/health`

#### Ping
**GET** `/ping`
